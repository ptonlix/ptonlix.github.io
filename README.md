# 陈富东的个人主页

[![Deploy to GitHub Pages](https://github.com/ptonlix/ptonlix.github.io/actions/workflows/deploy.yml/badge.svg)](https://github.com/ptonlix/ptonlix.github.io/actions/workflows/deploy.yml)

个人主页，使用 [Astro](https://astro.build) 构建，部署在 GitHub Pages。

## ✨ 特性

- 🎨 Terminal / Control-plane 风格设计，与 GitHub Profile README 统一
- 🌓 亮色/暗色主题自动切换
- 📱 响应式设计，完美支持移动端
- ⚡ 极速构建与加载
- 🌟 项目卡片自动从 GitHub API 获取 stars 数据
- 🔍 SEO 友好，包含 sitemap 和 Open Graph 图片
- ♿ 可访问性优化

## 🚀 本地开发

```bash
# 安装依赖
npm install

# 启动开发服务器
npm run dev

# 构建生产版本
npm run build

# 预览构建结果
npm run preview
```

## 📝 内容更新

主要内容配置在 `src/config.ts` 文件中，包括：

- 个人信息和联系方式
- 作品集（特色项目和归档项目）
- 工作经历和教育背景
- 技术栈和兴趣爱好

## 🛠️ 技术栈

- [Astro](https://astro.build) - 现代静态网站生成器
- TypeScript - 类型安全
- GitHub Actions - 自动部署
- GitHub API - 实时获取项目数据
